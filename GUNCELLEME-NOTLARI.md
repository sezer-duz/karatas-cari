# Android v1.1.0 → v1.1.1 güncellemesi

Mevcut GitHub deponun **kök dizininde** bulunman gerekir. Güncelleme ZIP içindeki tüm dosyaları depo köküne yaz. Eski `app/settings.gradle` dosyasını **sil**. Eğer önceki tüm proje `karatas-cari-main/` adlı bir alt klasördeyse bu klasörü taşıyarak `app/`, `.github/` ve Gradle dosyalarını depo köküne çıkar.

Bu yalnızca Android uygulaması kaynak kodunu etkiler, PHP/MySQL web sunucusunda güncelleme gerektirmez. APK derlendikten sonra web sunucusu `v1.35.8` veya uyumlu barkod kodu içermelidir.
